## 🎯 Learning Objectives

- Provision AWS infrastructure using Terraform.
- Automate cloud infrastructure deployments.
- Configure EC2 instances and security groups.
- Use Terraform variables and outputs.

- Manage infrastructure using Terraform CLI commands.

---

## 💻 Terraform Commands

### Initialise Terraform

```bash
terraform init
```

### Validate Configuration

```bash
terraform validate
```

### Preview Infrastructure Changes

```bash
terraform plan
```

### Deploy Infrastructure

```bash
terraform apply
```

### Destroy Infrastructure

```bash
terraform destroy
```
